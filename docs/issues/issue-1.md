# Issue #1: S1: Landing page live

## What to build

Deploy a landing page on Cloudflare Pages that positions pod-dex for B2B interview podcast teams. The page is the pre-sell gate: it has to convert well enough to validate the product before any pipeline code is written.

Page includes: positioning headline, sample outputs section showing what the product produces, clear pricing (LTD offer at \$199), and a Stripe Checkout CTA. Domain and product name must be confirmed before this goes live.

## Acceptance criteria

- [ ] Domain purchased and DNS pointed at Cloudflare Pages
- [ ] Product name decision made (pod-dex or final name)
- [ ] Landing page deployed to Cloudflare Pages with positioning, sample outputs, and \$199 LTD CTA
- [ ] Stripe Checkout configured for the \$199 one-time LTD payment (even if fulfillment is manual at this stage)
- [ ] LTD terms defined (episode cap / usage limits for lifetime customers)
- [ ] Page live and accessible at the chosen domain

## Blocked by

None — can start immediately.
